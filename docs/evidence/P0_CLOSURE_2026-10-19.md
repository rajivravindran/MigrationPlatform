## Rollout caveats closed

- **A2 mixed versions**: `FinalizeBatchInput` now carries the counter-derived `Status` *and* `DeriveFromStages=true`. A worker predating the change writes the counter status (its original behaviour); a current worker ignores it and derives the verdict. No path writes `failed` for an empty-status input any more.
- **A4 rollback**: `migration-admin merge-cursors [--connector <id>]` folds every `cursor.bySchedule.<id>.seen` into the connector-wide `cursor.seen` so an older build skips objects processed after the upgrade. Run it before rolling the orchestrator back; see ADR 0005.
